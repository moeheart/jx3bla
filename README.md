# 剑三警长(原剑网三战斗日志分析、奶歌复盘)

JX3 **B**attle **L**og **A**nalyser v8.16.6（已发布）

用于深入分析剑网三中茗伊战斗复盘的框架，包含对jcl/jx3dat复盘文件的支持。

目前可以对五奶进行深入分析。在收集足够的数据后，可以加入DPS的支持。

## 使用方法

`python3 MainWindow.py`

或者使用发布版本。

新版仅支持 50 级苍生铸世正式服，按 2026 年 10 月 29 日以后日志使用。程序统一使用当前正式服数据，不检查日志日期，也不切换旧等级或体服计算。

设置中的“剑三路径”留空时，会读取西山居启动器登记的正式服安装位置；手动填写的路径优先。选择记录者角色后点击“自动获取”，可推导对应格式的日志目录并刷新角色列表。识别失败会提示原因，保留原填写内容。

帮助文档详见程序内部介绍。

## 项目结构

沿用按功能分目录的结构，入口仍为根目录的 `MainWindow.py`（客户端）和 `server.py`（服务端）。

| 目录 | 内容 |
| --- | --- |
| `data/` | JCL/JX3DAT 日志读取与事件结构 |
| `replayer/` | 战斗、职业及首领复盘逻辑；名称和增益生成表 |
| `window/` | 客户端窗口 |
| `equip/` | 装备识别、属性计算；`resources/` 按赛季保存数据表 |
| `tools/` | 共用工具及独立校验、分析入口，见[工具说明](tools/README.md) |
| `release/` | 数据生成器、构建、验包与发布脚本 |
| `tests/` | 自动化回归测试，文件采用 `test_*.py` 命名 |
| `docs/` | 使用文档、版本记录与分析说明；`docs/160/evidence/` 保存苍生铸世开发取证原件 |
| `serverFunc/`、`database/`、`templates/`、`static/` | 服务端逻辑、数据库及网页 |
| `build/`、`dist/`、`backups/`、`.tmp/` | 本机构建产物、安装包、备份和临时工作文件，不提交 |

新增 Python 功能模块沿用 `AttributeDisplay.py`、`ValidateLuoyang.py` 这样的 PascalCase 命名；生成器放在 `release/`，采用 `*Generator.py`。原有模块名称保留。运行数据和生成输入继续留在 `equip/resources/`，原始字节码、取证报告和校验输出归入对应版本的文档目录，避免混进运行资源或工具代码。

## 心法支持

如果你有兴趣开发某个心法的复盘，可以考虑使用这个框架。它的功能有：

- 按照格式以统一流程拆解jcl/jx3dat，避免掉进数据格式的深海巨坑
- 将中间结果保存在内存中反复利用，并提供可视化的界面（例如处理进度）
- 对BOSS机制的专属分析，自动识别点名/上天/时间轴等场地因素
- 一些实用方法与类，例如tools.Functions中的心法颜色显示、buff覆盖率
- 自动化的上传与展示，完善的后处理流程

基本上使用这个框架可以节省大部分精力在无意义的问题上，把时间专注于逻辑部分。
