## 算法与维护入口

移出活动树的旧模块为 `ReplayBase.py`、`replayer/occ/MingZun.py`、`serverFunc/DailyUpdateDps.py` 和 `initDatabase.py`。旧文本 Lua 分析器 `LuaTableAnalyser` 与独立计数器 `SkillLogCounter` 可在上述 Git 起点查阅。JCL 与 JX3DAT 读取继续使用 `tools/LoadData.py` 的 `LuaTableAnalyserToDict`。仍有路由的历史首领复盘保留在 `replayer/boss/`。

正式与历史心法生成器共用 `release/XinfaAttributes.py`。两个历史取证命令继续可用，见[发布构建说明](../../release/README.md)。回放数据库恢复时从真实部署取得 DDL，在隔离库中验证五张表的字段顺序、引擎和编号计数器，操作见[数据库说明](../../database/README.md)。
