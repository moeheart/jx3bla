# 8.16.8 补丁：治疗复盘滚动与转阶段有效时间

本次继续使用8.16.8，不增加客户端版本号。修复治疗复盘时间轴下方被遮挡的问题，并依据现有普通、英雄洛阳之战实录补齐输出暂停区间。

## 治疗复盘布局

原有`after_idle`排版可能在团队、评分、说明框体创建之前执行，之后创建的框体仍停在旧坐标，盖住加高的时间轴横向滚动条。小屏外层Canvas还可能挡住同级嵌入面板的鼠标事件。

现在在所有面板创建后同步完成排版，明确面板层级；外层滚动容器持续响应窗口缩放。时间轴横条使用标准库主题滚动条，环境与个人技能两条Canvas共享横向位置。按实际字体和滚动条尺寸计算机制区高度，不再依赖固定高度与异步回调的执行顺序。

## 无效时间规则

本轮确认的区间只影响DPS，治疗仍按完整有效战斗时间计算。暂停标记不是NPC不可选或无敌属性；结论结合独立机制边界和逐事件输出检查。

一号必须是同一本体向玩家发送的有效暂停/启动配对；二号若巨剑已经存在、缺入场或期间仍有输出则不扣。五号必须有完整本体转场边界和目标退场证据，仍有煞将、剑符、飞兵或区间内有有效伤害时保留。缺结束信号或结束超过确认战斗终点时，不擅自补满无效区间。

所有候选检查跨NPC目标的玩家有效伤害及独立反射返回值，避免漏掉小怪、可击破物和反伤。现有消费端按`(start,end]`切换状态，一、二号在恢复机制边缘提前1毫秒结束掩码，保留恢复同毫秒的真实输出；证据分别保存机制终点和实际掩码终点。五号结束喊话之后至首次输出之间的沉默缺少独立禁攻边界，不扩扣；重铸期间本体和飞兵仍有输出，继续保留。

无效区间传入CombatTracker、个人技能统计及专属DPS表。通用DPS和花间的个人有效时间改用输出时钟；治疗继续使用治疗时钟。个人受控时间与无效区间重合时只扣一次。有效时间为零时保留原始总量，速率显示0，避免除零或巨大占位数。
