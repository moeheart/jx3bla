# 8.16.4 Bug 修复

本版本在已发布的 8.16.3 和当前 `codex/dev-8.16` 分支上整理并修复，不变更五首领的既有阶段与胜负判断。仅适用于 2026 年 10 月 29 日起的 50 级苍生铸世正式服数据；按正确输入使用，不添加日期校验或体服兼容分支。

## 更新记录

- 修复文件结构和命名不一致：保留原有按功能分目录的方式，统一新增工具与生成器命名，将开发取证原件归入文档目录，分开运行资源与开发资料。
- 修复安装包体积膨胀：移除未使用的 NumPy、AVIF 可选依赖和重复名称、公式及体服资源，统一构建清单。
- 修复自动识别路径失败：优先读取新启动器 `SOFTWARE\Kingsoft\SeasunGame\JX3` 的 `InstallPath`，检查用户/机器与 32/64 位注册表视图，识别正式服日志目录；保留手动路径优先，失败时不覆盖已有设置，刷新角色候选并清理失效缓存。
- 修复装备缺失时的属性处理：有当前正式服同心法或同家族样本时提供平均装备参考，明确显示“装备读取失败，数值仅供参考”；没有样本时保持缺失状态。修复跨场角色 ID 重用导致的装备串用，以及估算或缺失属性参与正式属性排名、评分或上传的问题。
- 修复多来源目标增益的归属：独立记录来源、目标、等级和到期时间，正确处理刷新、过期、覆盖与统计缓存；保留日志实际奇穴信息，供戍边强化虚弱判断使用。修复后仍保持伤害分摊守恒。

## 数据与证据边界

平均装备只收集可解析、槽位完整且没有未建模装备特效的正式服样本，不借用体服或旧赛季数据。9 份正式日志逐份核对 SHA256 后重新生成，与包内 JSON 完全一致：6 个角色样本，覆盖 5 个直接心法和 5 个普通/悟别名；其余心法保持无样本状态。估算和未标定属性均不能当作真实装备或完整校准结果。

目标减防的层级与多来源标记依据正式 `1.6.0.10009` 表核对；正式日志用于验证实际技能与奇穴读取。现有正式样例每种相关职业仅一名来源，无法单靠这些日志证明多来源游戏内叠加；多来源归属、独立刷新和过期由回归测试验证。戍边脚本分支另有较早客户端原件，未将其冒充 10009 同版本逐字取证。

## 验证与发布

全套 244 项自动测试通过，无跳过项。新增回归覆盖角色缓存隔离、无样本状态传播、参考属性排名/上传保护、正式服样本过滤、多来源目标增益及晚奇穴元数据；冻结验收还对排名和上传保护做失效检测。

最终 EXE 在空目录中完成七场正式回放：五首领各一场，以及 11 月 3 日的无界鲸鱼、无界奶毒样例；全心法复盘、隐藏首领/统计窗口、伤害分摊守恒与显示排序通过。冻结包内另用真实 Actor 全流程验证估算、无样本和混合状态，确认属性排名与上传受保护、实测伤害百分位保留。PNG/ICO + Tk、Excel 读写、13 项资源哈希及 126 个内嵌项目模块源码校验通过。

安装包为 `dist/剑三警长v8.16.4.exe`（与 `dist/j3jz.exe` 一致），35,872,993 字节（34.21 MiB），相较 8.16.3 的 66,188,678 字节缩小约 45.8%。SHA256：`4c58f2b7fe656853fea557a190215655adf6a116c3bf980689e23d09be8499ac`。
