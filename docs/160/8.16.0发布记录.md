## 发布流水线

正式版的洛阳之战始终使用本地 50 级属性计算，因此 `MainWindow.spec` 必须携带新季 11 份运行资源。原始 Buff 表和开发取证不进入 EXE，增益使用编译的 `NameCangsheng.py`；旧季 `Name.py` 保持不变。

发布脚本生成当前版本底表、独立构建、逐字节验包，再从空目录运行 EXE 冒烟，通过后才替换 `dist/j3jz.exe`。提交和推送为检查后的独立步骤，不再自动暂存无关工作区文件。图标生成只收录 PNG/ICO，排除缓存和本地调试脚本。

构建环境：Windows x64、Python 3.14、PyInstaller 6.17.0。
