# 8.16.8 复盘界面与时间轴修复

本轮处理2026年11月13日英雄洛阳之战实录反馈的战斗主表、个人奇穴和时间轴问题。装备模型、伤害归因及排名质量限制沿用8.16.7。

## 战斗主表

五首领共用居中的统计表，初始窗口根据实际表格高度和屏幕尺寸计算；可容纳25行时默认完整展示。小屏保留横纵滚动，拖动窗口后重新居中。阶段说明随宽度换行，导航与个人复盘按钮保持可用。

## 个人奇穴

原窗口固定读取`1..12`，在当前普通心法只有9项时抛出`KeyError: '10'`，使后续技能、时间轴及评分面板不能加载。现在只按数字槽位顺序显示实际非空名字，每行最多6项；缺项不补造奇穴，缺失或不可用快照继续提示获取方式。

本批英雄5场125份最终快照中，124份为完整9项，1份悟心法为完整4项；4月历史样本为10项。兼容测试另覆盖6项、12项、稀疏/空值及非法元数据。Python治疗与通用DPS窗口和旧版`static/HealerReplay.js`采用相同规则。

当前另行部署的SPA五奶组件仍固定12个展示位置，已有空值保护；它与本次Python异常是两个入口。本轮未修改该外部SPA，旧版JS修复只适用于实际引用`HealerReplay.js`的页面。

## 技能轴

洛阳五首领只保留明确机制。合并同机制的喊话、读条、阶段替代提示；仅在最终战斗边界内去重。周期性伤害以机制轮次记录，独立敌人的并发读条保留。史朝义总轴移除小怪“重斩”，原始事件及伤害统计继续保留。

颜色和图标由`replayer/boss/luoyangzhizhan/Timeline.py`统一映射：剑招用红色、巨剑/锁链/转场用紫色、火焰/爆弹用橙色、水浪/远程用蓝色、聚邪/残魂用青色。可用的对应图标优先使用，未随客户端打包的技能图标用现有相近符号替代；不将替代图标描述为该技能官方图标。

独立时间轴按实际文字宽度分轨，保留真实时间位置与导出顺序，并可纵向查看长战斗。五奶和花间个人复盘共用机制分轨组件，环境区独立滚动，与个人技能区共享水平时间位置。个人技能区保持80像素可见；小屏可继续滚动查看下方团队与评分。缺图、非法颜色采用可见后备显示。
