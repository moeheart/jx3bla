## 专属统计

### 突利和顺

- 本体 `139306` 与多个同名机制 NPC 按模板区分，避免名称相同就计入主目标。
- `45485` 潜渊之刺、`45486` 倒悬之墨、`45487` 玄溟奔涌、`45488` 浊浪登天、`45489` 死水微澜形成场地轴。
- `34238`、`34210` 分别配对潜渊与倒悬点名的获得/移除，刷新不重复计次；缺失移除时截止于本场结束并标注截断。
- 死水微澜读条进入专门区段，随后当前首领发出的 `33755` 技能启动标记结束该区段。通关样本该段为 12.965 秒。
- `34490` 坍缩力场在当前表中是减速及减少跳跃次数，不能据此扣除全团有效输出时间或当成全程眩晕。
- 玄溟奔涌、玄溟之火命中列为观察事件，不自动判责。

### 田承嗣

- 本体 `139329` 与天陨巨剑 `140384` 分列有效伤害与 DPS。
- 阶段仅按可观察事件划分：交战 → “全军准备”喊话 → 巨剑出场 → 巨剑重伤后；没有推断未验证的血量阈值。
- 通关样本巨剑出场 97.450 秒、重伤 117.814 秒，持续 20.364 秒；巨剑伤害合计 15,220,000。
- `34255` 鸣镝连珠、`34254` 千钧锤落、`34329` 以身承剑记录点名。`34329` 的 `atSilenceAll`、`atDisableMoveCtrl` 支持将该区间计入个人被控时间。
- 断岳横斩与枪林突刺记录受击。当前日志不能唯一确定重叠分摊责任人，因此不把所有被命中者直接判为失误。

### 伊曼双子

- 分列寂夜、逐焰本体伤害，以及不死机关伤害；通关样本双本体分别为 201,009,324 和 63,549,493。
- `34597` 记录逐焰锁定，`34504` 记录锁链横扫眩晕。技能 ID 与气劲 ID 的命名空间独立，不把 `34504` 错读成同 ID 的其它招式名。
- 以火环 NPC `139718` 的实际进入/离开标注火环区间，其余标注双子交战。两类区间均计有效时间，不推断固定 P1/P2 血量阶段。
- 场地轴包含逐猎爆弹、散雷延爆、锁链横扫、爆裂轰退、链坠天崩、链舞火环、焚天炽焰。

## 验证与限制

离线专属测试覆盖同名 NPC 排除、点名刷新、缺失移除、只减速不扣时间、巨剑死亡非通关、失败重置截断、承剑控制截断、双子双死亡要求、喊话来源与下一场污染，并检查所有环境轴图标实际随仓库提供。

```powershell
C:\Python314\python.exe -m unittest discover -s tests -p test_luoyang_first_three.py -v
C:\Python314\python.exe -m unittest discover -s tests -p test_luoyang_file_selector.py -v
C:\Python314\python.exe tools/ValidateLuoyangFirstThree.py <已备份的JCL目录> --output <本地验证输出.json>
```

上述 10 项机制/窗口数据契约回归、4 项文件选择回归，以及 10 份真实日志专属复盘均通过。文件选择覆盖 61 份完整保留、跨日期/地图隔离、同一天前后两次副本隔离、明确跨日选择仍完整保留。实际目录验证返回 5 场最近首领、61 份全部尝试，手选界面也提供全部 61 份。

真实日志额外验证了非负点名区间、点名/控制不超过裁剪边界、有效时长与裁剪一致、图标文件存在。全 Actor/心法链路验证由接入手册另行汇总。

当前机制与模板验收范围是这批 25 人普通体服样本；没有宣称 10 人或 25 人英雄机制已经实战验收。每次体服修改仍需重新核对。50 级新赛季的面板/rDPS 底层参数限制见[增益底表审计](增益底表审计.md)，专属伤害列使用日志的有效伤害。
